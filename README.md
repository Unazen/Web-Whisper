# Whisper local

Локальное веб-приложение: нажал на кнопку, наговорил, получил текст. Можно загрузить готовый аудио или видеофайл. Распознавание идёт на твоей машине через faster-whisper, в интернет ничего не уходит.

Стек: Python + FastAPI на бэкенде, чистые HTML/CSS/JS на фронтенде, оформление из рендер-сервиса (папка `static/css` и шрифты те же), автозапуск через systemd, HTTPS через Caddy.

## Что умеет

- запись с микрофона любого устройства, открывшего сайт (кнопкой или пробелом), индикатор громкости;
- загрузка своих файлов: mp3, wav, m4a, ogg, flac, mp4, mkv и другие, в том числе видео (берётся звуковая дорожка). Можно перетащить или выбрать сразу несколько, каждый становится отдельной записью;
- выбор модели Whisper с кратким описанием, скоростью, точностью и размером. Модели скачиваются прямо с сайта;
- язык: автоопределение или ручной выбор;
- текст появляется по мере распознавания, виден прогресс, этап (чтение файла, загрузка модели, распознавание) и оставшееся время;
- очередь с позициями, отмена записи в очереди и в процессе (частичный текст сохраняется);
- результат можно править, правки сохраняются сами; автокопирование в буфер для записей с микрофона и кнопка «Копировать»;
- скачивание: TXT, SRT с таймкодами, исходный файл, MP3 (из видео получится только звук);
- записи и файлы удаляются через 30 дней;
- модель грузится в память при первой расшифровке и выгружается через 5 минут простоя. Если на видеокарте не хватает свободной памяти (например, идёт рендер), расшифровка идёт на процессоре, а причина показана в карточке и в верхней строке.

## Установка

Всё скачивается с нуля, ничего не берётся из кэша Open WebUI.

```bash
cd ~/Apps/Web-Whisper
chmod +x setup.sh
./setup.sh
```

Скрипт создаёт `.venv`, ставит зависимости (включая cuBLAS и cuDNN для CUDA 12 через pip, системный CUDA Toolkit не нужен) и скачивает модель по умолчанию, large-v3 (около 3 ГБ). Остальные модели можно скачать позже на сайте в разделе «Модели Whisper».

Для MP3 нужен ffmpeg: `sudo pacman -S ffmpeg`. Без него остальное работает, не работает только кнопка MP3.

### Обновление с первой версии

Распакуй новый архив поверх папки проекта, затем:

```bash
./setup.sh
systemctl --user restart whisper-app
```

Папки `models/` и `data/` не трогаются: скачанная large-v3 остаётся, старые записи видны. Каталог моделей теперь лежит в `models/<имя>`, как и раньше.

## Проверка Whisper в консоли

```bash
source env.sh
python scripts/proto.py путь/к/аудио.mp3
python scripts/proto.py путь/к/аудио.mp3 --model large-v3-turbo
python scripts/proto.py путь/к/аудио.mp3 --device cpu
```

Скрипт показывает, на чём загрузилась модель, сколько заняло распознавание и во сколько раз оно быстрее реального времени. Если видеокарте не хватает памяти, он сам переходит на процессор и показывает, какие процессы её занимают.

Модели можно скачать и из консоли: `python scripts/download_model.py large-v3-turbo`.

## Запуск вручную

```bash
./run.sh
```

Откроется на `http://127.0.0.1:8765`. Микрофон в браузере работает на `localhost` и по HTTPS, но не по обычному `http://192.168.x.x`. Для доступа с других устройств нужен Caddy.

## HTTPS через Caddy

В `deploy/Caddyfile.example` пример:

```
whisper.lan:8443 {
	tls internal
	reverse_proxy 127.0.0.1:8765
}
```

Подставь свой хост и порт и добавь блок в существующий Caddyfile. По умолчанию приложение слушает только `127.0.0.1`, наружу его выставляет Caddy.

## Автозапуск (systemd)

Юнит пользовательский, рассчитан на папку `~/whisper-app`. Если проект лежит в другом месте (например, `~/Apps/Web-Whisper`), поправь пути `WorkingDirectory` и `ExecStart` в `deploy/whisper-app.service`:

```bash
mkdir -p ~/.config/systemd/user
cp deploy/whisper-app.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now whisper-app
loginctl enable-linger $USER
```

Логи: `journalctl --user -u whisper-app -f`.

## Настройки

Задаются переменными окружения (в юните через `Environment=`):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `WHISPER_HOST` / `WHISPER_PORT` | `127.0.0.1` / `8765` | адрес сервера |
| `WHISPER_MODEL` | `large-v3` | модель по умолчанию, если в браузере ничего не выбрано |
| `WHISPER_MODELS_DIR` | `models` | куда скачиваются модели |
| `WHISPER_VRAM_MARGIN_MB` | `600` | запас видеопамяти сверх потребности модели |
| `WHISPER_MIN_FREE_VRAM_MB` | не задано | жёсткий порог свободной видеопамяти вместо расчёта по модели |
| `WHISPER_IDLE_UNLOAD_SECONDS` | `300` | через сколько простоя выгружать модель |
| `WHISPER_RETENTION_DAYS` | `30` | через сколько дней удалять записи |
| `WHISPER_MAX_DURATION_SECONDS` | `1800` | максимальная длина записи с микрофона |
| `WHISPER_MAX_UPLOAD_DURATION_SECONDS` | `10800` | максимальная длина загруженного файла (3 часа) |
| `WHISPER_MAX_UPLOAD_MB` | `2048` | максимальный размер загружаемого файла |
| `WHISPER_CPU_THREADS` | `6` | потоков при работе на CPU |
| `WHISPER_DATA_DIR` | `data` | где лежат записи |

## Где что лежит

```
server/        бэкенд (main, jobs, transcriber, models, catalog, audio, storage, export)
static/        интерфейс (index.html, css/, js/, fonts/)
scripts/       проверка в консоли и загрузка моделей
deploy/        systemd-юнит и пример Caddyfile
data/records/  записи: исходный файл, meta.json, result.json, mp3 по запросу
models/        файлы моделей
```

## Возможные проблемы

**Видеопамять занята (`CUDA failed with error out of memory`).** На карте может висеть что-то ещё: Open WebUI с Whisper, ollama, рендер. Посмотреть, кто держит память: `nvidia-smi`. Приложение в этом случае не падает, а считает на процессоре и пишет причину в карточке записи. large-v3 нужно около 5,5 ГБ свободных, large-v3-turbo около 4 ГБ. Освободи память или выбери модель полегче.

**Ошибка `av.open() got an unexpected keyword argument 'metadata_errors'`.** Новые версии PyAV (17 и выше) несовместимы со встроенным декодером faster-whisper. Приложение и `proto.py` используют собственный декодер (`server/audio.py`), поэтому работают с любой версией.

**Страница пустая или не открывается.** Проверь по порядку: `curl -i http://127.0.0.1:8765/api/status` (должен вернуть JSON), в браузере F12, вкладки Console и Network (ошибки и коды ответов у `/static/...`), `journalctl --user -u whisper-app -n 50`. Если открываешь с другого устройства, приложение должно стоять за Caddy: напрямую оно слушает только `127.0.0.1`.

**Текст не копируется автоматически.** Браузеры разрешают запись в буфер только в ответ на действие пользователя. Chrome обычно разрешает, Firefox строже. Если не сработало, кнопка «Копировать» подсветится. Для загруженных файлов автокопирования нет, чтобы несколько файлов не затирали друг друга.

**Распознавание на CPU медленное.** large-v3 на процессоре работает около реального времени или медленнее. Для запасного режима поставь рядом medium или small.

**Рендер и Whisper вместе.** Если модель уже на GPU, а ты запустил тяжёлый рендер, они делят 12 ГБ. Через 5 минут простоя модель выгружается сама, можно поставить `WHISPER_IDLE_UNLOAD_SECONDS=60`.
